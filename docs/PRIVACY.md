# Key Overlay privacy policy

_Last updated: Fri Oct 23, 2026

Key Overlay is a Chrome extension that shows the keys you press and the clicks you make as an on-screen overlay, in tabs you turn it on for.

## What it reads

When you turn Key Overlay on for a tab, it reads the keys you press and the clicks you make in that tab, so it can draw them on screen. It does not run in tabs you haven't turned it on for.

## What it does with that

It draws them on your screen, and nothing else. Keys and clicks are:

- never stored, on your device or anywhere else
- never logged
- never sent anywhere. The extension makes no network requests at all.
- never shared with, sold to, or seen by anyone, including the developer

Sensitive fields, such as passwords, credit card numbers, and one-time codes, are shown only as `•`. By default, so is anything typed into a form embedded from another site, such as a payment field.

## What it stores

Using Chrome's built-in extension storage, Key Overlay saves:

- **Your display settings:** position, size, speed, spacing, and which options are on. If you use Chrome sync, Chrome syncs these between your devices like any other extension setting.
- **Which tabs the overlay is on**, as Chrome tab numbers. This list is cleared when you close the tab or the browser.

Neither contains anything you typed.

## Permissions

- **activeTab** and **scripting:** to add the overlay to a tab when you turn it on.
- **storage:** to save the settings above.
- **Access to all sites (optional):** asked for when you first turn it on, so the overlay can come back after a tab navigates to another site. You can decline or remove it at any time in `chrome://extensions`. The overlay still only runs in tabs you've turned on.

## A note on screen sharing

Anything the overlay shows is visible to anyone who can see your screen, including in screen shares and recordings. Turn the overlay off before typing anything secret that isn't in a password or card field.
